How AI requests are routed

Strict failover order. A provider that fails twice is skipped for {{ settings.ai_circuit_cooldown_seconds }} s (circuit breaker), then retried.

{{ ui.ai_chip(disclaimer=False) }}
    {% for p in providers %}
  1. {{ p.rank }}{{ p.label }}{{ p.status | humanize }}
  2. {{ icon("arrow-right", "size-4") }}
    3. {% endfor %}
  3. {{ icon("wifi-off", "size-4") }}AI unavailable

Every feature first asks the Gemma gateway (llama.cpp behind an OpenAI-compatible API), then Gemma in Docker (Ollama) as the local failsafe, then Claude as the last resort. When all three fail, pages show "AI unavailable" and fall back to deterministic rules - pre-recorded videos, safety checks and payroll maths keep working.
